# 冻结评测结果摘要

测量批次：2026-11-05。本页为便于展示的汇总，不修改原始结果。

## 输入与方法

3 款游戏；检索 40 题（24 开发、16 留出）；有效调查 25 题（20 开发、5 留出），5 道撤下记录另存。资料、题目和审核绑定冻结；每道检索题预热一次、测量五次。

| 配置 | Recall@10 | nDCG@10 | 留出 Recall@10 | 检索 P95 ms |
|---|---:|---:|---:|---:|
| BM25 | 0.2991 | 0.2346 | 0.4062 | 86.7 |
| Dense | 0.3266 | 0.3258 | 0.3646 | 554.8 |
| Hybrid | 0.4030 | 0.3640 | 0.5000 | 563.3 |
| Hybrid＋BGE Reranker | 0.4000 | 0.3808 | 0.4271 | 6658.3 |

Hybrid 相比 Dense 的 Recall@10 增加约 7.6 个百分点。Reranker 总体排序分数更高，但留出召回下降，默认仍关闭。延迟是本机该批次检索耗时，不是完整调查 SLA。

## 能证明与不能证明的事

- 19 道可执行 Oracle 工具计划的保存复测为 19/19；6 道无计划不计通过或业务失败。
- 历史全量回归为 1020 项通过；这不是 1020 个真实用户任务，更不是 Agent 准确率。
- 历史真实 Agent 记录混有不同模型和中断；没有一个同配置完整批次可用于宣称当前总体准确率。
- 无答案误返回、否定/反例标签对齐、小样本及 AI 评委可见性仍有限制。LLM Screening 不在上述四组纯离线结果内。
