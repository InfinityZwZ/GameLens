# 图片与历史记录说明

## 图片来源

- `assets/workspace.png`：当前网页资源的离线首页，无真实任务。
- `assets/investigation-trace.png`、`assets/investigation-result.png`：当前网页读取脱敏历史记录的回放截图，不是新运行。
- `assets/gamelens-architecture.png`、`assets/gamelens-workflow.png`：逻辑架构与流程概览，不是运行数据。

历史调查针对 AppID 251570 的一条更新公告讨论区。截图保留原答案、工具错误及限制，没有把失败改成成功。历史只采集前 200/558 条，不能代表完整玩家意见，答案也没有被本次独立重新评分；个别“普遍”等措辞不应解读为统计推断。

当前采集默认已改为 500，上限 1000，历史截图不等于当前参数。原轨迹含“系统本地日期”等旧术语；当前实现统一北京时间。

## 脱敏与生成

只抽取问题、答案、计划、工具名和简短结果；省略原始留言、玩家身份、源 URL、原始工具负载、本机路径和用量。所有浏览器请求被本地拦截；没有 Steam、供应商请求，也没有借截图触发真实调查。

`evidence/preview-provenance.json` 保存原记录哈希和省略项；原件保留本地，哈希本身不代表原答案全部正确。
